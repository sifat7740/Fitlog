                 FitLog — Workout Library 
                 
   FitLog is a dark, no-nonsense gym companion built with Next.js. Browse a library of workouts, lock lifts into your daily plan, save favorites for later, and track your progress — all in a clean, responsive interface       

   =>Technologies used
   Next.js
   TypeScript
   Tailwind CSS
   React Context API
   localStorage

   =>key features 
   Workout Library
   Workout Details 
   Today's Plan & Saved Lists
   My Plan Dashboard
   Persistent State
   Toast Notifications
   Fully Responsive
   Custom 404 Page & Loading States
